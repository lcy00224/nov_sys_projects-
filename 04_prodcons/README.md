# 多线程并发控制：生产者-消费者模型

## 项目描述
基于 POSIX Threads (`pthread`) 库，实现了一个 2 个生产者、3 个消费者的多线程并发模型，保证对共享有界缓冲区的安全访问。

## 核心功能与技术点
1. **同步与互斥**：使用 `pthread_mutex_t` 互斥锁保护共享的库存变量，防止并发自增导致的“丢失更新”问题
（复现了经典的数据竞争场景）。
2. **条件变量**：使用 `pthread_cond_t` 实现线程间的通知。当库存满时，生产者调用 `pthread_cond_wait` 阻塞；
消费者消费后唤醒。反之亦然。
3. **防止虚假唤醒**：在调用 `pthread_cond_wait` 时，严格使用 `while` 循环判断条件
（如 `while (buffer == MAX_SIZE)`），而不是 `if`，确保线程被唤醒后重新校验临界条件。
4. **参数传递**：封装 `ThreadArg` 结构体，通过传递指针的方式给不同的生产者/消费者线程传递独立 ID。

## 面试话术
“多线程的难点不在于 API 怎么写，而在于并发状态下的逻辑安全。在实现这个模型时，我深刻体会到了 `while` 循环
的必要性。因为在多对多的场景下，线程被唤醒不代表条件就立刻满足了，必须重新检查，否则就会出现数组越界或库
存为负数的情况。”
