# C 语言底层模型验证 (C Language Basics)

## 项目描述
通过编写可编译的 C 语言小测试用例，配合 GDB 调试，深入验证 C 语言在实际 x64 Linux 系统下的底层内存布局与关键字语义。

## 核心验证点
1. **内存对齐规则**：通过 `sizeof` 和 `offsetof` 验证了 `struct {char; int; short;}` 在 64 位系统下占据 12 个字节。亲手画出了 Padding 补齐的内存布局图，理解 CPU 按字长读取的效率优化。
2. **多级指针与回调**：手写函数指针数组，并将函数指针作为参数传递，验证了 C 语言的“回调机制”底层运行原理。
3. **const 与 static 语义**：通过故意编译报错，验证了 `const int *` 与 `int * const` 的区别（区分指针本身只读与指向数据只读）；验证了 `static` 局部变量生命周期贯穿整个程序的特性。

## 面试话术
“我在学习 C 语言时不仅看教材，更偏向于用 GDB 和 `offsetof` 去验证底层。比如内存对齐，我不只背概念，我能在纸上画出对齐的内存块，并解释为什么这样设计能提高 CPU 缓存命中率。”
