# 文件 I/O 与系统调用实现 (MyCat)

## 项目描述
脱离 C 语言标准库（如 `fopen/fgets`），完全基于 Linux 内核提
供的系统调用 `open/read/write/close`，从零手写实现了一个类似 `cat` 的命令行工具。

## 核心功能与技术点
1. **系统调用**：使用 `open` 获取文件描述符（fd），利用 `read` 循环读
取数据到用户态缓冲区，再通过 `write` 输出到标准输出（fd=1）。
2. **异常处理**：处理了文件不存在（通过 `perror` 打印底层报错）、短读
（实际读入字节 `n` 小于请求字节）等边界情况。
3. **缓冲区对比**：编写额外测试程序，对比了标准库 `printf`（用户态带
缓冲）与系统调用 `write`（直接进内核）的数据流向差异，理解了重定向（`>`）时全缓冲与行缓冲的行为区别。

## 面试话术
“面试官您好，在写这个 `mycat` 时我踩过一个坑：一开始 `write` 写死了 1024 字节，导致终端打出乱码。后来我明白了必须
用 `read` 的返回值 `n` 来控制 `write` 的长度。这也让我彻底懂了 fd（文件描述符）其实只是内核数组的下标。”
