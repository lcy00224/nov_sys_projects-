# 11月 Linux 系统编程实战项目

本项目是个人在学习 Linux C/C++ 后端开发过程中，纯手写实现的核心实战代码。

## 📂 项目结构
*   `01_c_verify`: C语言底层验证（指针、内存对齐、const/static/volatile）。
*   `02_cat`: 基于系统调用的文件 I/O 实现（mycat）。
*   `03_minishell`: 基于 fork/exec 与管道重定向的迷你 Shell。
*   `04_prodcons`: 多对多线程池与生产者-消费者模型（Mutex/Cond）。
*   `05_epoll_echo`: 基于非阻塞 I/O 与 epoll 的高并发 TCP 服务器（含自定义协议解决粘包）。

## 🛠️ 技术栈
C, Linux, 多进程, 多线程, IPC, Socket, epoll, Git.
