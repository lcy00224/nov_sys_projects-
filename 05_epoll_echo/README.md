# 高并发网络服务器 (Epoll Echo Server)

## 项目描述
基于 Linux epoll 模型实现的单线程高并发 TCP 服务器。

## 核心技术点
1. **I/O 多路复用**：使用 `epoll_create`, `epoll_ctl`, `epoll_wait` 构建事件驱动模型，主线程无需阻塞，
单线程即可同时处理多个客户端连接。
2. **非阻塞 I/O**：使用 `fcntl` 将监听的 `server_fd` 和收发的 `client_fd` 设置为 `O_NONBLOCK`，
防止因网络延迟导致主线程被卡死。
3. **健壮性处理**：精准捕获 `EAGAIN`/`EWOULDBLOCK` 错误码，区分“真正的读错误”与“非阻塞下的无数据状态”。
4. **资源管理**：客户端断开时，先通过 `epoll_ctl` 从内核红黑树中移除监听，再 `close` 释放文件描述符，
杜绝内存与描述符泄漏。

## 面试话术
“我手写过基于 epoll 的并发服务器。与传统的阻塞式服务器不同，epoll 把‘等待数据’的工作交给了内核。主线程只用调用
 epoll_wait 睡眠，一旦有事件发生，内核就会把就绪的 fd 返回给我。同时，结合非阻塞 read，完美解决了单线程下
 TCP 半包/延迟导致的阻塞问题。”
