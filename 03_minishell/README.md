# Linux 迷你 Shell 实现 (Mini Shell)

## 项目描述
使用 C 语言从零实现了一个类 Bash 的迷你命令行解释器，深入实践了 Linux 进程控制、进程间通信（IPC）及 I/O 重定向。

## 核心功能与技术点
1. **基础命令执行**：通过 `fork()` 创建子进程，子进程调用 `execvp()` 替换为新程序，父进程通
过 `waitpid()` 阻塞等待回收，避免僵尸进程。
2. **内建命令拦截**：对于 `cd` 和 `exit`，不执行 `fork`，而是由父进程直接调用 `chdir()` 切换工作目录，
保证 Shell 状态一致。
3. **管道通信 (|)**：解析到管道符时，使用 `pipe()` 创建管道。通过 `dup2()` 将左侧进程的
标准输出重定向至管道写端 `fd[1]`，右侧进程标准输入重定向至读端 `fd[0]`，实现了 `ls -l | wc -l` 复合指令。
4. **后台运行 (&)**：通过拦截 `&` 符号，父进程不执行阻塞等待，配合 `waitpid(-1, NULL, WNOHANG)` 进行非阻
塞轮询回收，实现了后台任务不卡死终端。

## 面试话术

柱：它把默认连向屏幕的1 号孔，换成了管道的写端。同时我还踩过父进程不 `close` 管道导
致 `wc` 进程死等的坑，这让我对进程资源管理印象深刻。”
